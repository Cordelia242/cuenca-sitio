# Recibí mi sueldo, ¿y ahora?

Te depositaron **Bs 5.000**. Antes de gastar un solo boliviano, dale un trabajo a cada uno.

## Pasos

1. **Registra el ingreso.** Toca **+**, elige **Ingreso**, escribe Bs 5.000 y el título "Sueldo". En **¿Para qué es?**, elige **Disponible para asignar**. Elige la cuenta del banco y guarda.
2. **Abre el plan.** Ve a **Planes** (en la web, **Plan**). Verás los Bs 5.000 en **Disponible para asignar**.
3. **Toca Asignar** y reparte en este orden:
    1. Lo que no puede esperar: vivienda, servicios, comida, transporte.
    2. Cuotas de deudas y el pago de tu tarjeta.
    3. Lo que apartas para gastos irregulares y metas.
    4. Lo que te queda para gustos: salidas, ropa.
4. **Llega a cero.** Cuando veas **Todo asignado**, terminaste.

!!! tip "Más rápido"
    Si tus presupuestos tienen metas, usa **Completar metas**. Si tus meses se parecen, usa **Auto-asignar el mes** con **Asignado el mes pasado**.

## Ejemplo

| Presupuesto | Asignado |
|---|---:|
| Alquiler o anticrético | Bs 1.800 |
| Luz, Agua, Gas, Internet y celular | Bs 450 |
| Comida | Bs 1.100 |
| Transporte | Bs 350 |
| Salud | Bs 200 |
| Fondo de emergencia | Bs 500 |
| Metas | Bs 300 |
| Ocio y salidas | Bs 300 |
| **Total** | **Bs 5.000** |

!!! tip "Programa tu sueldo"
    Si cobras siempre el mismo día, crea un [movimiento programado](../app/programadas.md) para tu sueldo. Así Cuenca lo registra solo y tú solo lo repartes.
