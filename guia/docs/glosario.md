# Glosario

**A cargo de**
:   En un espacio compartido, la persona responsable de un presupuesto y qué parte le toca pagar.

**Actividad**
:   Lo que gastaste o recibiste con un presupuesto en el mes.

**Asignar**
:   Darle dinero a un presupuesto, sacándolo de **Disponible para asignar**.

**Asignado**
:   Lo que le diste a un presupuesto este mes.

**Atajo**
:   Un movimiento ya armado que registras con un toque, desde el teléfono, un widget o el reloj. En la web se llama **Acción rápida**.

**Conciliar**
:   Confirmar que un movimiento aparece en el extracto de tu banco. Un movimiento puede estar **Pendiente** o **Conciliado**.

**Cubrir**
:   Mover dinero desde un presupuesto a otro que quedó en negativo.

**Cuenta**
:   Un lugar donde tienes dinero o deuda: el banco, el efectivo, la tarjeta de crédito.

**Cuenta de seguimiento**
:   Una cuenta que no entra al plan (**Otro activo** u **Otro pasivo**). Solo suma o resta a tu patrimonio.

**Disponible**
:   Lo que te queda para gastar en un presupuesto.

**Disponible para asignar**
:   El dinero que tienes y todavía no tiene trabajo. La meta es dejarlo en cero.

**Espacio**
:   Un conjunto propio de cuentas, presupuestos y moneda. Tienes uno **Personal** y puedes crear otros, incluso compartidos.

**Etiqueta**
:   Contexto opcional de un movimiento, como "Viaje" o "Reembolsable". Un movimiento puede tener varias.

**Grupo**
:   Un conjunto de presupuestos parecidos, como "Servicios básicos".

**Meta**
:   Lo que necesita un presupuesto: apartar un monto, rellenar hasta un monto o juntar un saldo.

**Movimiento**
:   Cada vez que el dinero entra, sale o cambia de lugar: un gasto, un ingreso o una transferencia.

**Movimiento programado**
:   Un movimiento que se repite y que Cuenca registra solo en su fecha.

**Patrimonio**
:   Lo que tienes menos lo que debes.

**Perfil de préstamo**
:   Las reglas de un préstamo: interés, frecuencia de pago, recargos.

**Presupuesto**
:   Un "sobre" de dinero con un propósito: Comida, Luz, Transporte. Cada gasto va a uno.

**Respaldo**
:   Un archivo con todos tus datos para guardarlos o pasarlos a otro dispositivo.

**Sobregasto**
:   Cuando gastas más de lo que tenía un presupuesto y queda en negativo.

**Transferencia**
:   Dinero que pasa de una cuenta tuya a otra. No cambia tu plan.
