# Teléfono y web

Cuenca tiene tres partes: la app del teléfono, la versión web para la computadora y una app para el reloj. Las tres trabajan con el mismo plan, pero cada una tiene su fuerte.

## La app del teléfono

Es la parte principal de Cuenca y está disponible para Android.

- Funciona **sin conexión** y **sin crear una cuenta**.
- Es ideal para anotar un gasto en el momento, en la tienda o en el micro.
- Abajo tienes cuatro pestañas: **Inicio**, **Planes**, **Movimientos** y **Más**. En el centro está el botón **+** para registrar un movimiento nuevo.
- En **Más** encuentras todo lo demás: cuentas, etiquetas, préstamos, movimientos programados, reportes, configuración y respaldo.

## La versión web

Es Cuenca para la computadora, pensada para una pantalla grande.

- Necesita una **cuenta de Cuenca**, que creas con tu cuenta de Google.
- Es cómoda para tareas largas: revisar el mes, ordenar movimientos, importar el extracto del banco o mirar reportes con calma.
- Tiene un menú lateral agrupado en **Día a día**, **Organizar**, **Préstamos y tasas**, **Análisis**, **Asistente** y **Espacio y ajustes**.
- Se puede usar casi entera con el teclado.

## La app del reloj

Si tienes un reloj con Wear OS conectado a tu teléfono, puedes registrar movimientos con la voz o con un toque usando atajos.

## Qué hay en cada una

La mayoría de las funciones están en el teléfono y en la web. Estas son las diferencias:

| Función | Teléfono | Web |
|---|:---:|:---:|
| Plan, movimientos y cuentas | ✓ | ✓ |
| Movimientos programados y calendario | ✓ | ✓ |
| Reportes | ✓ | ✓ |
| Préstamos | ✓ | ✓ |
| Espacios compartidos | ✓ | ✓ |
| Funciona sin cuenta y sin conexión | ✓ | — |
| Asistente por voz y reloj | ✓ | — |
| Widgets en la pantalla de inicio | ✓ | — |
| Restaurar un respaldo y borrar todo | ✓ | — |
| Asistente por chat | — | ✓ |
| Análisis (patrimonio, flujo, tendencias, edad del dinero) | — | ✓ |
| Herramientas (reglas, duplicados, auditoría) | — | ✓ |
| Deshacer y rehacer con el teclado | — | ✓ |

!!! tip "¿Cuál uso?"
    Puedes usar solo el teléfono y te alcanzará para todo lo esencial. La web es un complemento muy útil si te gusta revisar tus cuentas con calma en la computadora.

!!! note "Cómo leer esta guía"
    Cuando un paso cambia entre el teléfono y la web, verás dos pestañas: **En el teléfono** y **En la web**. Elige la que usas y la guía la recordará en las demás páginas.
